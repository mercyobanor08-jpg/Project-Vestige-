VESTIGE - installable app (PWA)
================================

EASIEST: use it right now
1. Open the live link you were sent on your phone.
2. Android (Chrome): tap the Install button that appears, or menu > Install app.
   iPhone (Safari): tap Share > Add to Home Screen.

PUT IT ON YOUR OWN ADDRESS (2 minutes, free)
1. Unzip this folder.
2. Go to app.netlify.com/drop and drag the whole folder onto the page.
   (GitHub Pages or Cloudflare Pages also work.)
3. Netlify gives you an https link. Open it on any phone and install as above.
4. After the first visit the app works offline, including photos.

STORE VERSIONS (later)
Paste your hosted link into pwabuilder.com to get an Android package for the Play Store.
An iPhone App Store version needs a Mac and an Apple developer account.

NOTES
- Keep all files together in the same folder.
- Do not open index.html by double-clicking: install and offline need an https link.
- The 3D globe and 3D part models load three.js from the internet on the first visit and are then saved for offline use.
- Unofficial student project, not endorsed by NASA. Photos: NASA imagery.
